Course Identity

Teaching networks from concepts to working communication systems

The course begins with why networks are needed and the vocabulary used to describe them, then builds through data communication, layered network models, common protocols, Internet concepts and wireless networking. Security principles and practical simulations are integrated to connect theory with observable network behaviour.

Nodes & Links Packets Bandwidth & Latency LAN · MAN · WAN Analog & Digital Signals OSI Model TCP/IP HTTP · FTP · SMTP DNS · DHCP IPv4 · IPv6 Routing Wireless Networks Network Security Packet Tracer
Learning Focus

Students are guided to understand:

  • How networked devices communicate and exchange data.
  • How layered network models organize communication functions.
  • How addressing, protocols, DNS, routing and client-server communication support the Internet.
  • How wireless networks differ from wired communication environments.
  • How basic security practices and simulation tools support safer, more reliable networks.
Teaching Approach

Visualize → connect → simulate

Networking concepts become easier to understand when students can see how data moves, connect protocol behaviour to real services, and test configurations through simulation.

01 · Visualize

Make invisible communication visible

Layered models, signals, packets and addressing are introduced through clear diagrams and communication flows before configuration begins.

02 · Connect

Relate protocols to everyday Internet use

Students connect concepts such as DNS, HTTP, DHCP, IP addressing and routing to familiar network and web interactions.

03 · Simulate

Test network behaviour practically

Packet Tracer activities reinforce topology design, IP configuration, connectivity testing and troubleshooting.

Curriculum Architecture

Course learning pathway

The public portfolio groups the course into four academic phases rather than reproducing internal assessment or timetable information.

01

Network Foundations

Establishing the vocabulary and communication concepts needed to reason about networks.

  • What a network is and why networks are needed
  • Nodes, links, packets, bandwidth and latency
  • LAN, MAN and WAN
  • Real-world networking applications
  • Sender, receiver, medium, message and protocol
  • Analog vs digital signals and data representation
02

Models, Protocols & Data Flow

Understanding how layered architectures organize communication across networked systems.

  • OSI model and its seven layers
  • TCP/IP model and relationship with OSI
  • HTTP, FTP, SMTP, DNS and DHCP
  • Encapsulation and decapsulation
  • Movement of data across network layers
  • Protocol roles in end-to-end communication
03

Internet & Wireless Networking

Connecting network models to Internet addressing, routing and modern wireless communication.

  • IPv4 and IPv6 addressing
  • DNS and website location
  • Routing basics and packet switching
  • Client-server communication
  • Wi-Fi, Bluetooth and cellular networks
  • Access points, SSIDs and wireless configuration
04

Security & Network Simulation

Introducing safe network practices and reinforcing concepts through practical simulation.

  • Malware, phishing and hacking attempts
  • Firewalls and encryption basics
  • Secure passwords and safe network practices
  • Introduction to VPNs
  • LAN design and IP configuration
  • Connectivity testing and troubleshooting
