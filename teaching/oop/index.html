Course Identity

Teaching OOP as software design, not only syntax

The course begins by contrasting procedural and object-oriented approaches, then develops the concepts students need to model software using classes and objects. From there, the focus expands to inheritance, polymorphism, abstraction, encapsulation, object relationships, UML, exception handling, file persistence, Python object protocols and introductory design patterns.

Learning Outcomes

Students are guided to:

  • Explain core object-oriented programming concepts clearly.
  • Design programs using classes, objects and meaningful relationships.
  • Apply OOP principles to realistic software problems.
  • Write cleaner, modular and reusable Python code.
  • Analyze and improve the structure of object-oriented programs.
Teaching Approach

From concept to software design

I teach each OOP idea as a design decision: first why it exists, then how it behaves, and finally how it changes the structure of a real program.

01 · Understand

Build the mental model

Concepts are introduced through clear comparisons, real-world analogies and small class-based examples before students write larger programs.

02 · Implement

Move immediately into Python

Live examples and guided practice connect terminology to constructors, methods, inheritance hierarchies, abstract interfaces and object relationships.

03 · Design

Combine concepts in systems

Students progress from isolated OOP features to multi-class applications where design, persistence, error handling and maintainability work together.

Curriculum Architecture

Course learning pathway

The public portfolio groups the taught material into four academic phases rather than reproducing internal timetable or assessment details.

01

Object-Oriented Foundations

Establishing the transition from procedural programming to class-based software design.

  • Procedural programming vs OOP
  • Classes, objects and instances
  • Constructors, __init__ and self
  • Attributes, methods and object state
  • Inheritance, overriding and super()
  • Polymorphism and flexible method behaviour
02

Core OOP Principles

Developing stronger control over interfaces, implementation details and object state.

  • Abstraction with abstract classes and methods
  • ABC and @abstractmethod
  • Abstraction working with polymorphism
  • Encapsulation and controlled access
  • Public, protected and private conventions
  • Getters, setters and data protection
03

Object Relationships & Modelling

Moving from individual classes to software structures composed of collaborating objects.

  • Inheritance vs composition
  • Composition and strong ownership
  • Aggregation and independent object lifecycles
  • UML for visualising object-oriented design
  • Class, object, sequence and use-case diagrams
  • Git/GitHub workflows for organized development
04

Reliable & Pythonic Software

Extending OOP into practical software concerns and reusable design techniques.

  • Exception handling and custom exceptions
  • File handling and persistent data
  • Combining classes, files and error handling
  • Static-method practice in class-based systems
  • Python dunder methods and operator behaviour
  • Creational, structural and behavioural design patterns
