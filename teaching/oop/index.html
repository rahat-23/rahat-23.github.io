Object-Oriented Programming

A Python-based course focused on designing structured, reusable and maintainable software through classes, objects and the core principles of object-oriented programming, followed by object relationships, error and file handling, Python object protocols and introductory design patterns.

Course Overview

From OOP foundations to maintainable Python software

The course starts with the transition from procedural programming to object-oriented thinking and builds through classes, objects, constructors, inheritance, polymorphism, abstraction and encapsulation. Students then study composition, aggregation and UML before applying OOP to exception handling, data persistence, Python dunder methods and introductory software design patterns.

Learning Outcomes

By the end of the course, students should be able to:

  • Explain core Object-Oriented Programming concepts.
  • Design programs using classes and objects.
  • Apply OOP principles to solve real-world problems.
  • Write clean, modular and reusable Python code.
  • Analyze and improve object-oriented program structure.
Teaching Approach

Concept → example → implementation → reflection

The course is taught through progressive explanation, live Python examples, guided practice and applied software scenarios. Students move from understanding individual OOP principles to combining them in maintainable multi-class programs.

Conceptual Foundation

Understand the design idea

Each topic begins with the software-design problem it addresses, supported by simple analogies and object-oriented terminology.

Implementation

Translate concepts into Python

Students implement concepts through classes, methods, object relationships, exception handling, persistence and reusable program structures.

Applied Practice

Connect OOP to realistic systems

Practice activities use small software systems and progressively larger scenarios to strengthen design reasoning and code organization.
