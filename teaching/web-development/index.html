Course Identity

Learning web development by building websites

The course develops web-design skills through progressive implementation. Students first learn how web pages are structured, then add visual styling and layout, adapt interfaces for different screen sizes, consider accessibility and usability, introduce basic interactivity and media, and finally prepare a complete site for public deployment.

HTML5 Semantic Markup Links & Images Forms CSS Box Model Flexbox CSS Grid Responsive Design Accessibility JavaScript Foundations Transitions & Animation Media & SVG SEO & Deployment
Learning Focus

Students are guided to:

  • Structure clear, semantic and maintainable web pages.
  • Design visually coherent interfaces using modern CSS.
  • Create layouts that adapt across desktop and mobile screens.
  • Apply basic accessibility and usability principles.
  • Introduce forms, media, animation and basic interactivity appropriately.
  • Refine and deploy a complete website as a public-facing project.
Teaching Approach

Structure → style → adapt → publish

Students build continuously. Each new concept improves an existing page or project so that web-development skills accumulate into a complete website rather than remaining isolated exercises.

01 · Structure

Build meaningful content

Students begin with semantic HTML, page structure, navigation, images, forms and organized project folders.

02 · Style

Develop visual hierarchy

CSS, typography, the box model and layout techniques are applied to turn raw pages into coherent user interfaces.

03 · Adapt

Design for different users and screens

Responsive layouts, Flexbox, Grid, accessibility and usability principles strengthen the quality of the student-built websites.

04 · Publish

Move from classroom work to the web

Students refine performance, basic SEO and project quality before deploying a completed website through GitHub Pages.

Curriculum Architecture

Course learning pathway

The public portfolio presents the course as a progression in web-development capability rather than reproducing weekly assessment and submission details.

01

Web & HTML Foundations

Understanding how web projects are structured and how meaningful content is represented.

  • How the web works and roles in web development
  • Development tools and project structure
  • HTML document structure and metadata
  • Semantic elements, headings and paragraphs
  • Internal and external links
  • Images, alternative text, lists, tables and forms
02

CSS & Visual Design

Turning semantic content into readable, organized and visually coherent interfaces.

  • CSS syntax and selectors
  • Box model, colors and fonts
  • Positioning and layout foundations
  • Typography and advanced text styling
  • Hover states and pseudo-classes
  • Progression toward portfolio-style pages
03

Responsive Layout & Accessibility

Designing interfaces that remain usable across screen sizes and user needs.

  • Viewport and fluid design concepts
  • Media queries
  • Flexbox layout and responsive navigation
  • CSS Grid and combined Grid/Flexbox layouts
  • Accessibility principles and ARIA basics
  • WCAG awareness and usability review
04

Interaction, Media & Motion

Adding controlled interactivity and richer presentation without losing usability.

  • Advanced form inputs and validation concepts
  • Introduction to JavaScript
  • CSS transitions and keyframe animations
  • Hover interactions
  • Audio, video and iframe embedding
  • Inline SVG and media-rich pages
05

Project Refinement & Deployment

Bringing the technical and design strands together into a finished public website.

  • Integrated responsive and accessible project development
  • Project planning and iterative refinement
  • Performance-oriented improvements
  • SEO fundamentals
  • GitHub Pages deployment
  • Presentation of completed website work
Student Project Development

From the first HTML page to a deployed website

Project work develops incrementally across the course, allowing students to see a website evolve as new technical and design skills are introduced.

Stage 01

Build the structure

Students create basic pages, then extend them into multi-page websites with links, images and organized content.

Stage 02

Develop the visual system

Existing pages are styled using CSS, typography and layout techniques, including portfolio-style interfaces.

Stage 03

Improve the experience

Projects are adapted for responsive layouts, accessible interaction, forms, media and controlled animation.

Stage 04

Publish the website

Students refine their final work, consider performance and SEO basics, and deploy a live version using GitHub Pages.

Project-Based Teaching

Students create complete web experiences

The project pathway connects individual technical exercises to a larger design outcome. Rather than treating HTML, CSS, responsiveness, accessibility and deployment as separate topics, students apply them progressively to websites they build throughout the course.
