Course Identity

Teaching students to move from raw data to defensible insight

The course introduces data science as an analytical process rather than a collection of isolated tools. Students examine how data is generated, identify quality problems, prepare datasets, perform exploratory analysis, evaluate statistical relationships and make evidence-based interpretations using real-world data.

Data Life Cycle Data Quality Missing Data Data Cleaning EDA Descriptive Statistics Visualization Correlation Hypothesis Testing Chi-Square T-Tests ANOVA Pandas NumPy
Learning Focus

Students are guided to:

  • Understand data types, data quality and the role of data in analytical decision making.
  • Clean and prepare imperfect real-world datasets for analysis.
  • Use exploratory analysis and visualization to identify patterns and relationships.
  • Interpret descriptive statistics, correlation and statistical test results.
  • Apply hypothesis testing to support evidence-based conclusions.
  • Use Python analytical libraries to organize, analyse and communicate data.
