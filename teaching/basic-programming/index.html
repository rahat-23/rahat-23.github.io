Programming Foundations

Basic Programming

An introductory Python course focused on logical thinking, problem solving and understanding how computers execute programs. The course moves from computing fundamentals and data representation into Python syntax, functions, control flow and introductory data structures.

Undergraduate 16 Weeks 3 Hours / Week Python Live Coding Practical Exercises
Weekly Plan Learning Outcomes All Courses
Course Overview

From computing fundamentals to structured Python programming

The course begins with what programming is, how computers represent information, the history and evolution of programming languages, and the role of high-level languages. Students then learn Python through variables, data types, functions, scope, conditions, loops, functional constructs and introductory data structures.

Course Objectives

After completing the course, students should be able to:

  • Understand how computers process data.
  • Explain basic programming concepts and terminology.
  • Develop logical and algorithmic thinking.
  • Write simple and structured programs using Python.
