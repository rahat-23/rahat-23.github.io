Course Overview

From computing fundamentals to algorithmic thinking

The course begins with how computers represent information and how programming languages evolved, then moves into Python fundamentals, control flow, functions, data structures and introductory algorithmic reasoning.

Bits & Bytes Binary ASCII & Unicode Programming Languages Variables & Data Types Control Flow Functions Recursion Lists Searching & Sorting Stacks & Queues Trees & Graphs Big-O
Learning Outcomes

By the end of the course, students should be able to:

  • Explain how data and instructions are represented in a computer.
  • Write and debug basic Python programs using variables, conditions, loops and functions.
  • Break problems into smaller computational steps.
  • Use basic data structures and understand their purpose.
  • Compare simple searching and sorting strategies.
  • Develop an introductory understanding of algorithmic efficiency.
