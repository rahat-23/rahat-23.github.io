Basic Programming

An introductory Python course designed to build computational thinking, problem-solving ability and a clear understanding of how programs execute. My teaching moves from computing fundamentals and data representation to structured Python programming and introductory data structures.

Course Identity

Teaching programming as a way of thinking

The course introduces programming from first principles. Students begin with how computers represent and execute information, how programming languages developed, and why high-level languages matter. The course then builds practical Python skills through variables, data types, functions, control flow and structured problem solving before introducing fundamental data structures.

Programming Concepts Binary & Data Representation Programming Languages Python Variables Data Types Strings Functions Scope Conditions For & While Loops Lambda / map / filter Linear Data Structures Trees · Tries · Graphs
Learning Outcomes

Students are guided to:

  • Understand how computers process and represent data.
  • Explain basic programming concepts and terminology.
  • Develop logical and algorithmic thinking.
  • Write simple, structured programs using Python.
