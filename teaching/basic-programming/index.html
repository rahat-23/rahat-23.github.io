Basic Programming

An introductory Python course designed to build computational thinking, problem-solving ability and a clear understanding of how programs execute. My teaching moves from computing fundamentals and data representation to structured Python programming and introductory data structures.

Course Identity

Teaching programming as a way of thinking

The course introduces programming from first principles. Students begin with how computers represent and execute information, how programming languages developed, and why high-level languages matter. The course then builds practical Python skills through variables, data types, functions, control flow and structured problem solving before introducing fundamental data structures.

Programming Concepts Binary & Data Representation Programming Languages Python Variables Data Types Strings Functions Scope Conditions For & While Loops Lambda / map / filter Linear Data Structures Trees · Tries · Graphs
Learning Outcomes

Students are guided to:

  • Understand how computers process and represent data.
  • Explain basic programming concepts and terminology.
  • Develop logical and algorithmic thinking.
  • Write simple, structured programs using Python.
Teaching Approach

Explain → code → practise

The course is taught through short conceptual explanations, live Python demonstrations and guided programming practice so that students move quickly from understanding an idea to using it.

01 · Explain

Start with the computing idea

New topics are introduced through clear definitions, visual examples and links to how computers, programming languages and software actually work.

02 · Code

Translate the idea into Python

Live coding demonstrates syntax, execution and debugging while connecting each line of code to the concept being taught.

03 · Practise

Strengthen independent problem solving

Guided exercises progress from small tasks to structured problems involving functions, control flow, collections and data structures.

Curriculum Architecture

Course learning pathway

The public portfolio groups the taught material into four learning phases, showing the academic progression without reproducing internal timetable or assessment details.

01

Computing & Programming Foundations

Building the conceptual foundation needed before students begin writing code.

  • What programming is and how programs solve problems
  • Bits, bytes, binary and data representation
  • Text representation and character encoding
  • History and evolution of computing and programming languages
  • Machine, assembly and high-level languages
  • Compiler, interpreter and code execution concepts
02

Python Core

Moving from programming concepts into Python syntax and data manipulation.

  • Development environments and first Python programs
  • Comments, variables and assignment
  • Integers, floats, strings and Booleans
  • String operations, indexing and slicing
  • Lists, tuples, dictionaries and sets
  • Type awareness and structured data handling
03

Structured Programming

Developing reusable logic and program flow for increasingly complex problems.

  • Functions, parameters and return values
  • Local and global variable scope
  • Conditional statements and logical operators
  • User input and type conversion
  • For loops, while loops and nested iteration
  • Break, continue, loop else and formatted output
04

Functional Thinking & Data Structures

Extending core programming into compact functional constructs and foundational data structures.

  • Lambda functions and anonymous expressions
  • map() and filter()
  • Python lists and introductory NumPy arrays
  • Linked lists, stacks and queues
  • Trees and recursion
  • Tries, graphs and real-world data-structure examples
Practice-Led Learning

Building confidence through progressive programming practice

Classroom practice is used to reinforce each topic immediately, helping students connect syntax with reasoning rather than memorising code patterns.

Foundational Practice
