Data Structures & Algorithms

A Python-based course in efficient problem solving, data organization and algorithmic reasoning. My teaching emphasizes not only how an algorithm works, but how to trace it, analyse its cost, compare alternatives and justify an appropriate solution.

Course Identity

Teaching students to choose, analyse and justify solutions

The course treats data structures and algorithms as a unified problem-solving framework. Students learn how the organization of data influences operations and performance, how algorithms scale with input size, and how different structures and strategies create different computational trade-offs.

Learning Focus

Students are guided to:

  • Explain the purpose of algorithms and abstract data types.
  • Analyse algorithm efficiency using asymptotic reasoning.
  • Implement and compare linear and non-linear data structures.
  • Trace searching, sorting, tree and graph algorithms step by step.
  • Select and justify algorithm-design strategies for structured problems.
  • Connect correctness, efficiency and implementation choices.
Teaching Approach

Explain → trace → implement → compare

DSA becomes meaningful when students can move fluently between a concept, a hand-worked trace, a Python implementation and an efficiency argument.

01 · Explain

Build the structural idea

Each topic begins with the problem a structure or algorithm is designed to solve, supported by real examples and visual models.

02 · Trace

Reason step by step

Whiteboard and digital-board dry runs make pointers, comparisons, recursive calls and traversal states visible before coding.

03 · Implement

Translate reasoning into Python

Students implement core structures and algorithms, test behaviour and connect code statements to the traced algorithm.

04 · Compare

Evaluate the trade-offs

Alternative approaches are compared using complexity, stability, memory behaviour, structure requirements and problem context.

Curriculum Architecture

Course learning pathway

The public portfolio presents the curriculum as a progression of problem-solving capabilities rather than reproducing internal weekly or assessment schedules.

01

Algorithmic Foundations & Complexity

Establishing the language used to reason about computational solutions.

  • Data structures, algorithms and abstract data types
  • Programming versus algorithm design
  • Systematic problem-solving processes
  • Input size and operation-count reasoning
  • Best, average and worst cases
  • Big-O, Big-Theta and growth of functions
  • Time-space trade-offs
02

Arrays, Searching & Sorting

Studying indexed data and the algorithms used to locate and order information.

  • Arrays, Python lists and direct access
  • Insertion, deletion, traversal and operation cost
  • Linear and binary search
  • Bubble, selection and insertion sort
  • Stability and comparative analysis
  • Merge, quick and heap sort
  • Divide-and-conquer reasoning in sorting
03

Linear Data Structures

Moving from contiguous storage to linked and restricted-access structures.

  • Singly, doubly and circular linked lists
  • Traversal, search, insertion and deletion
  • Linked-list reversal and structural reasoning
  • Stacks and LIFO behaviour
  • Infix-to-postfix conversion and postfix evaluation
  • Queues, circular queues, priority queues and deques
  • Comparing arrays, lists, stacks and queues
04

Trees, Graphs & Traversal

Extending data organization from sequences to hierarchies and networks.

  • Tree terminology and binary-tree structures
  • Binary search trees and ordered search
  • Inorder, preorder, postorder and level-order traversal
  • Tree height, balance and efficiency
  • Graph representations and connectivity
  • Breadth-first and depth-first search
  • Weighted graphs, shortest paths and spanning trees
05

Search & Algorithm Design Strategies

Bringing together data structures and algorithmic reasoning to choose strategies for larger problem classes.

  • State-space search and frontier-based reasoning
  • BFS, DFS, depth-limited and iterative-deepening search
  • Uniform-cost, greedy best-first and A* search
  • Brute-force design
  • Divide and conquer
  • Greedy algorithms
  • Dynamic programming and repeated-subproblem reasoning
